# 🏦 Banking RAG Chatbot

AI-powered Banking RAG Chatbot built using React.js, Spring Boot, Python, FastAPI, FAISS, and MySQL.

## Features

- User Registration & Login
- JWT Authentication
- Banking FAQ Question Answering
- Retrieval-Augmented Generation (RAG)
- FAISS Vector Database
- FastAPI AI Service
- Spring Boot Backend APIs
- React Frontend
- Chat History Management
- MySQL Database Integration

## Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Java
- Spring Boot
- MySQL
- JWT

### AI Engine
- Python
- FastAPI
- FAISS
- Sentence Transformers

## Project Structure

```
banking-rag-chatbot/
├── frontend/
├── backend/
├── ai-engine/
```

## How to Run

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
mvn spring-boot:run
```

### AI Engine

```bash
python -m uvicorn ai_server:app --reload --port 8000
```
